### 아날로그 컴퓨터 & 디지털 컴퓨터

> 아날로그 컴퓨터 (증폭회로, 바늘시계, 빠르고, 정확 X)
> 
- 데이터 표현
    - 온도 , 전압, 진동 등과 같이 연속적으로 변하는 데이터를 효율적으로 처리
- 동작 방식
    - 특정 물리 현상을 이용해서 실시간으로 값을 처리
- 장점
    - 연속적으로 변하는 물리량을 빠르고 효율적으로 처리하는데 강점

> 디지털 컴퓨터 (논리회로, 전자시계, 계산, 느리고, 정확)
> 
- 데이터 표현
    - 0과 1의 비트로 표현되는 이산적 데이터를 처리
- 동작 방식
    - 정해진 명령어들로 구성된 프로그램에 의해 순차적으로 동작
- 장점
    - 정확성이 높고. 프로그래밍이 가능해서 범용적으로 다양한 작업에 사용

### CPU

- 레지스터
    - CPU 내부의 임시 기억 장치 (속도가 가장 빠름)
- 연산장치
    - 가산기 - 덧셈
    - 보수기 - 보수하여 뺄셈
    - 누산기 - 연산 결과 일시 기억
    - 상태 레지스터 - 상태 정보 기록
- 제어장치
    - 프로그램 카운터 - 다음에 수행할 명령어 번지를 기억

### 주 기억 장치

- RAM - 휘발성, 작업대 역할
- SRAM - 빠르고, 집적도 낮고, 재충전 X
- DRAM - 느리고, 집적도 높고, 재충전 O
- ROM BIOS - 펌웨어, CMOS로 설정 가능, 비휘발성, 플래쉬 메모리 (전기)
    - POST (자체진단), 날짜, 전원관리, 부팅 순서, 시스템 암호, 기본 글꼴, 칩셋 정보, 플러그 앤 플레이, 하드디스크타입, 안티바이러스 설정 등을 함
- 캐시 메모리 - 주 기억장치에 접근 속도 개선을 위해 사용
- 가상 메모리 - 보조 기억장치를 주 기억장치처럼 사용
- 플래쉬 메모리 - MP3, 디카에서 사용
- 속도 : 레지스터 > 캐시 메모리 > 주 기억장치 > 보조 기억장치

### 보조 기억장치

- SSD - HDD 보다 성능이 좋음
- 파티션 - 분할
- 포맷 - 지우고 초기화
- RAID
    - 스트라이핑 - 큰 파일을 나눠서 기록
    - 미러링 - 동일하게 기록

### 메인보드

- 버스
    - 데이터, 주소, 제어 신호 전송에 사용되는 통로
    - 내부 버스, 외부 버스, 확장 버스
- USB
    - 기존의 직렬, 병렬, PS/2 포트를 통합한 직렬 포트의 일종
    - 빠른 속도로 데이터를 전송
    - 주변 장치를 최대 `127`개 까지 연결 가능
    - 플러그 앤 플레이 설치를 지원하는 외부 버스
    - 컴퓨터를 종료하거나 다시 시작하지 않아도 연결 및 연결 해제 가능
    - 3.0은 `파란색`
- 채널
    - CPU와 입출력장치 사이의 속도 차이 문제를 해결
- 인터럽트 (응급상황)
    - 외부, 내부, 소프트웨어 등이 있음

### 하드디스크 연결 방식

- SATA 방식 (직렬)
    - 컴퓨터에서 하드디스크를 연결할 때 사용
    - 직렬 인터페이스 방식을 사용
    - PATA 방식보다 데이터 전송 속도가 빠르다
    - 핫 플러그인 기능을 지원
- EIDE
    - IDE의 확장판으로 주변 기기를 4개까지 연결하는 방식
