### 언어 번역(실행) 방식

- 컴파일러
    - 한번에 목적파일을 생성 후 실행
- 인터프리터
    - 한줄씩 코드 실행

### 객체 지향 언어 (OOP) 특징

- 추상화
- 캡슐화
- 다형성
- 상속성

### 클라이언트 / 서버

- 정보를 제공받는 곳은 클라이언트, 정보를 제공해주는 곳은 서버
- 모두 처리능력을 가지고 있음
- 분산 처리 환경에서 적합

### 웹 프로그래밍 언어

- HTML5 - 플러그인 (ActiveX) 없이도 웹 서비스를 이용 (클라이언트)
- ASP - 서버 측, WIndows에서만 이용
- PHP - 서버 측, Linux, Unix, Windows에서 사용
- JSP - 서버 측, 다양한 운영체제에서 사용
