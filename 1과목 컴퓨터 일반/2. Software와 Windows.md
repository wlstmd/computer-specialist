### 컴퓨터 단위

> 용량
> 
- BIT
- BYTE (8Bit)
- KB (1024Byte)
- MB ( 1024KB)
- GB (1024MB)
- TB (1024GB)
- PB (1024TB)

> 속도
> 

ms (10⁻³) → μs (10⁻⁶) → ns (10⁻⁹) → ps (10⁻¹²) → fs (10⁻¹⁵) → as (10⁻¹⁸)

| 단위 | 이름 | 초로 표현 | 의미 |
| --- | --- | --- | --- |
| **ms** | 밀리초 (millisecond) | 10⁻³초 | 0.001초 |
| **μs** | 마이크로초 (microsecond) | 10⁻⁶초 | 0.000001초 |
| **ns** | 나노초 (nanosecond) | 10⁻⁹초 | 0.000000001초 |
| **ps** | 피코초 (picosecond) | 10⁻¹²초 | 1조분의 1초 |
| **fs** | 펨토초 (femtosecond) | 10⁻¹⁵초 | 1000조분의 1초 |
| **as** | 아토초 (attosecond) | 10⁻¹⁸초 | 100경분의 1초 |

> 구성
> 
1. Bit
2. Nibble (4Bit)
3. Byte (8Bit)
4. Word (명령 단위)
5. Field
6. Recode
7. File
8. DB

### 문자코드

- BCD - 6Bit
- ASCII - 7Bit (통신용)
- EBCDIC - 8Bit
- UNICODE - 16Bit (국제문자)

### 운영체제의 목적

- 응답시간 단축
- 처리능력 향상
- 신뢰도 향상
- 사용가능도 향상

### 시스템 프로그램 - 운영체제 프로그램

- 제어 프로그램
    - 감시 프로그램
    - 작업 관리 프로그램
    - 데이터 관리 프로그램
- 처리 프로그램
    - 서비스 프로그램
    - 문제 처리 프로그램
    - 언어 번역 프로그램

### 소프트웨어 종류

- 프리웨어 - 대가 없이 무료
- 오픈소스 - 소스코드까지 무료
- 셰어웨어 - 일정 기간 동안 무료
- 베타버전 - 일반인 테스트
- 상용 - 돈을 받고 판매
- 유틸리티 - 컴퓨터 동작에 필수 X

### 운영체제 운영방식

- 일괄처리 - 한꺼번에 처리
- 실시간 처리 - 바로바로 처리
- 다중프로그래밍 - 여러 개의 프로그램을 동시에 처리
- 시분할 처리 - 시간을 분할하여 처리
- 듀얼코어
    - 다중처리 - 여러개의 CPU로 연산능력 향상
    - 듀플렉스 - 고장을 대비하여 여러개의 CPU 사용
- 분산 처리 - 네트워크로 작업, 서버/클라이언트 방식

### Windows 특징

- GUI 방식
- 선점형 멀티테스킹
- 선점형은 Ctrl + Shift + ESC를 눌러 작업 강제 종료 가능
- 멀티 테스킹은 여러개의 작업을 동시에 가능
- OLE (개체 연결 포함) 지원
- NTFS 파일 시스템 지원
    - FAT 방식에 비해 우수
    - 볼륨크기 256 TB 제한

### Windows 단축키

- `Ctrl` - 비연속적인 선택, 복사
- `Shift` - 연속적인 선택, 이동
- `F1` - 도움말 표시
- `F2` - 이름 바꾸기
- `F3` - 검색
- `F5` - 새로고침
- `F11` - 창을 전체화면으로 표시
- `Ctrl + ESC` - 시작 메뉴
- `Ctrl + A` - 전체 선택
- `Ctrl + Z` - 실행 취소
- `Ctrl + W` - 탭 닫기
- `Alt + F4` - 프로그램 종료
- `Alt + Enter` - 속성 (선택한 아이콘)
- `Alt + Tab` - 창 전환 (프로그램 목록이 보임)
- `Alt + ESC` - 창 전환
- `Alt + Space` - 창 조절 메뉴
- `Alt + Print Screen` - 활성화 된 창만 캡쳐
- `Shift + F10` - 바로가기 메뉴 (마우스 우클릭)
- `Shift + Delete` - 영구 삭제
- `Windows + D` - 바탕화면 보기
- `Windows + E` - 탐색기
- `Windows + R` - 실행 창
- `Windows + Pause` - 시스템 창
- `Windows + 방향키` - 에어로 도킹

    - 레지스트리에 문제가 발생하면 시스템 부팅이 안될 수 있음

### Windows 도구

- 디스크 속성
    - 디스크 정리 - 불필요한 파일 제거, 용량 확보
    - 오류 검사 - 물리적, 논리적 오류 검사
    - 최적화 및 조각 모음 - 단편화 제거, 속도 향상
- 휴지통
    - 드라이브 (디스크) 마다 따로 설정 가능
    - 오래된 파일부터 삭제
    - 실행 및 복사가 불가능
- 영구 삭제
    - USB, 네트워크처럼 외부에서 삭제된 경우
    - DOS (명령어 프롬프트)에서 삭제된 경우
    - Shift로 삭제된 경우
    - 휴지통 속성 변경된 경우
- 확장자
    - 파일명의 마침표 뒤에 붙이는 문자
- 연결프로그램
    - 파일을 실행했을 때 자동으로 실행되는 프로그램
- 메모장
    - TXT 형식
    - OLE(문서에 이미지 삽입) 지원 안됨
- 바로가기 아이콘
    - LNK 확장자
    - 삭제 시 원본에 영향이 가지 않음
